# Unified abstract ordnance employment

Aircraft-carried stores and SAM interceptors share the Module ordnance catalog, distinguished by employment category and platform compatibility, so both can use the same authored envelope, guidance, hit-probability, effect-speed, and effect-power language while aircraft loadouts and SAM launchers retain separate ammunition ownership. Aircraft employment uses a cancellable flight-level preparation phase followed by release into a persistent pending ordnance effect; authorized SAM launches skip the aircraft preparation phase but create the same pending effect, and released effects resolve at exact scheduled campaign times without simulated projectile entities. This was chosen over launcher-embedded interceptor definitions, duplicated aircraft/SAM resolvers, and moving missile entities because it preserves source-specific authorization and inventory rules while giving all munitions one deterministic, explainable delayed-effect model.
